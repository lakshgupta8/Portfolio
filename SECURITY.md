# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/lakshgupta8/Portfolio/security/advisories/new)
rather than opening a public issue. You can also email lakshya1176@gmail.com.

This is a static personal site with no backend, user accounts or stored data. Reports about dependencies,
the build pipeline or the deployed site's headers are all welcome.

## Supported versions

Only the latest commit on `main` is deployed and supported.
